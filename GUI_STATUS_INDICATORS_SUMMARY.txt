WHAT WAS ADDED:
───────────────

A professional status indicator bar that displays 5 critical telemetry values:

  1. 🟢 CONNECTION STATUS
     ├─ Green = Healthy D-Bus communication
     ├─ Red = Communication alarm active
     └─ Always shows connection health at a glance

  2. 🔋 BATTERY VOLTAGE
     ├─ Displays voltage in volts (V)
     ├─ Example: 13.2 V
     └─ Critical for power system monitoring

  3. 💨 FAN RPM
     ├─ Shows actual fan speed (rotations per minute)
     ├─ Example: 70 RPM when running
     └─ Indicates heater is actively heating

  4. 🔥 HEATER TEMPERATURE
     ├─ Combustion chamber temperature in °C
     ├─ Example: 145°C when running
     └─ Key indicator of heating performance

  5. 🌡️ INTERNAL SENSOR TEMPERATURE
     ├─ Internal sensor reading in °C
     ├─ Example: 28°C
     └─ Useful for troubleshooting sensor issues

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

LIVE DATA SOURCES:
──────────────────

All values are pulled directly from the D-Bus heater service:

  D-Bus Path                          → Display Element
  ─────────────────────────────────────────────────────────
  /Dc/0/Voltage                       → 🔋 Battery Voltage
  /Status/FanRpmActual                → 💨 Fan RPM
  /Temperatures/Heater                → 🔥 Heater Temperature
  /Temperatures/Internal              → 🌡️ Internal Temperature
  /Alarms/Communication               → 🟢 Connection Status

All values update in real-time as the heater operates.
